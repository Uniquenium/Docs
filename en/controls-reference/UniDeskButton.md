# UniDeskButton Type
A button

| Control Type | Element |
|-------------|---------|
| Source File | `Unidesk/UniDeskButton.qml` |
| Inherits | [QtQuick Button](https://doc.qt.io/qt-6.8/qml-qtquick-controls-button.html) |

## Properties

### `property bool disabled`
Whether the button is disabled.
Default is `false`.

### `property string contentText`
Text in the button.

### `property string iconSource`
Icon URL in the button.

### `property double radius`
Button corner radius.

### `property double iconSize`
Button icon size.

### `property double borderWidth`
Button border width.

### `property color borderColor`
Button border color.

### `property int mouseX`
X coordinate of the mouse in the button.

### `property int mouseY`
Y coordinate of the mouse in the button.
