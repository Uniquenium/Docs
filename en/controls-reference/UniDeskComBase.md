# UniDeskComBase Type

Basic component control, serving as the parent class for component controls in the Uniquenium visual editor, providing common properties and behaviors for all components.

| Project | Description |
|---------|-------------|
| Control Type | Visual Control |
| Source File | `UniDesk/Controls/UniDeskComBase.qml` |
| Inherits | QtQuick Item |
| QML Import | `import UniDesk.Controls 1.0` |

## Properties

### `property string identification`
Unique identifier for the component instance, automatically generated by the system when a component is created.

### `property string typeName`
Type name of the component (e.g., "MyPlugin.MyComponent").

### `property var componentData`
Component data object, storing all property values of the component.

### `property bool selected`
Whether the component is currently selected in the editor.

### `property bool inDesignMode`
Whether the component is in design mode (editor state).

## Methods

### `function save()`
Save current property values to the data object.

### `function reload()`
Reload component data, discarding unsaved changes.

### `function remove()`
Delete the component from the system.

## Basic Usage

```qml
import UniDesk.Controls 1.0

UniDeskComBase {
    id: myComponent
    identification: "com_a1b2c3d4"
    typeName: "ClockPlugin.ClockComponent"

    onSelectedChanged: {
        console.log("Selected state changed:", selected)
    }
}
```

## Notes

- This control is typically used internally by the Uniquenium editor and is not directly created by users.
- When developing plugins, components should inherit from this control to obtain unified edit behavior.
