# UniDeskText Type
Text

| Control Type | Element |
|-------------|---------|
| Source File | `UniDesk/UniDeskText.qml` |
| Inherits | [QtQuick Text](https://doc.qt.io/qt-6.8/qml-qtquick-text.html) |

## Properties

### `property color textColor`
Text color. Default is black in light mode and white in dark mode.

### `property url fontSource`
File path for custom font. Default is empty string.

### `property string fontFamily`
Font family. Default is "Microsoft YaHei".

### `property double fontSize`
Font size. Default is 13.
