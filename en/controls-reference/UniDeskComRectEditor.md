# UniDeskComRectEditor Type

Component rectangle editor control, providing rectangle area editing functionality (drag-to-move, edge resize, corner resize, and other interactions) for components in the Uniquenium visual editor.

| Project | Description |
|---------|-------------|
| Control Type | Visual Control - Editor Only |
| Source File | `UniDesk/Controls/UniDeskComRectEditor.qml` |
| Inherits | QtQuick Item |
| QML Import | `import UniDesk.Controls 1.0` |

::: warning Editor Only
This control is mainly used internally by the Uniquenium visual editor. Ordinary developers building custom components typically do not need to use it directly.
:::
