# UniDeskComBasicOptions 类型

组件基础选项面板控件，在 Uniquenium 可视化编辑器中显示选中组件的基础属性编辑 UI（如位置、尺寸、不透明度等通用属性）。

| 项目 | 说明 |
|------|------|
| 控件类型 | 可视化控件（Control） - **编辑器专用** |
| 源代码文件路径 | `UniDesk/Controls/UniDeskComBasicOptions.qml` |
| 继承 | QtQuick Item |
| QML 导入方式 | `import UniDesk.Controls 1.0` |

::: warning 编辑器专用
本控件主要供 Uniquenium 可视化编辑器内部使用，普通开发者在构建自定义组件时通常不需要直接使用。
:::
