# UniDeskComRectEditor 类型

组件矩形编辑器控件，在 Uniquenium 可视化编辑器中提供组件的矩形区域编辑功能（拖拽移动、边缘缩放、角点缩放等交互）。

| 项目 | 说明 |
|------|------|
| 控件类型 | 可视化控件（Control） - **编辑器专用** |
| 源代码文件路径 | `UniDesk/Controls/UniDeskComRectEditor.qml` |
| 继承 | QtQuick Item |
| QML 导入方式 | `import UniDesk.Controls 1.0` |

::: warning 编辑器专用
本控件主要供 Uniquenium 可视化编辑器内部使用，普通开发者在构建自定义组件时通常不需要直接使用。
:::
