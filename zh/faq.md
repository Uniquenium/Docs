# 常见问题 FAQ

这里汇总了用户在使用 Uniquenium 过程中最常遇到的问题。如果你没有找到答案，欢迎在 GitHub 提交 Issue。

## 安装与启动

### Q: 编译时提示「找不到 Qt6」或 CMake 报错

**A:** 请确保：
1. 已正确安装 Qt 6.5.0+，并在安装时勾选了所需模块（Core, Widgets, Quick, QuickControls2, DBus, Core5Compat, LabsPlatform, Concurrent）
2. 配置 CMake 时正确指定了 Qt 路径：
   ```bash
   cmake -B build -DCMAKE_PREFIX_PATH="C:/Qt/6.8.3/msvc2022_64"
   ```
3. 已安装 ECM（Extra CMake Modules）

### Q: 程序一闪而过，没有任何窗口显示

**A:** 请尝试以下步骤：
1. 检查托盘区（右下角任务栏）是否有 Uniquenium 图标，程序默认最小化到托盘
2. 如果没有托盘图标，使用命令行启动查看错误信息：
   ```bash
   .\build\Release\Uniquenium0.exe --debug
   ```
3. 确保显卡驱动已更新到最新版本
4. 尝试在软件渲染模式下运行（性能较低）：
   ```bash
   set QMLSCENE_DEVICE=softwarecontext
   .\build\Release\Uniquenium0.exe
   ```

### Q: 安装程序被 Windows Defender / SmartScreen 拦截

**A:** 这是正常现象，因为程序没有购买代码签名证书。请：
1. 点击「更多信息」→「仍要运行」
2. 或右键安装程序 → 属性 → 勾选「解除锁定」→ 确定

### Q: 旧版 Windows 10 壁纸功能异常

**A:** 部分旧版本 Windows 10（1809 之前）的壁纸 API 存在兼容性问题，建议升级到 Windows 10 21H2 或 Windows 11。

## 使用操作

### Q: 如何添加组件到桌面？

**A:** 操作步骤：
1. 打开主面板（默认快捷键：`Ctrl + Alt + U`）
2. 点击左侧「+ 新建页面」或选择已有页面
3. 点击「添加组件」按钮
4. 从组件列表中选择需要的组件类型
5. 拖拽调整组件位置和大小

### Q: 如何删除组件？

**A:** 有三种方式：
1. 选中组件后按 `Delete` 键
2. 右键组件 → 选择「删除」
3. 在页面管理窗口的组件树中右键 → 「删除」

### Q: 组件不小心拖到屏幕外找不到了怎么办？

**A:** 打开页面管理窗口（设置 → 页面管理），在组件树中选中该组件，右侧属性面板中重置 X/Y 坐标为 0。

### Q: 如何调整组件的层级（Z 轴顺序）？

**A:** 
1. 选中组件
2. 右键 → 选择「上移一层」/「下移一层」/「置于顶层」/「置于底层」
3. 或在组件树中直接拖拽调整顺序

## 主题与外观

### Q: 如何切换深色/浅色主题？

**A:** 
1. 右键托盘图标 → 设置 → 外观
2. 选择主题模式：跟随系统 / 浅色 / 深色
3. 也可以使用快捷键快速切换（需先在设置中绑定）

### Q: 亚克力模糊效果不显示

**A:** 亚克力效果依赖：
- Windows 10 1803+ 或 Windows 11
- 显卡支持硬件加速
- 在设置 → 外观中确认已开启「启用亚克力效果」

如果仍然不显示，尝试更新显卡驱动。

### Q: 可以使用自定义壁纸吗？

**A:** 可以！支持：
- 本地图片（JPG/PNG/BMP/WebP）
- 多张图片轮播
- 自定义 API 接口获取网络壁纸
设置路径：设置 → 外观 → 壁纸

## 快捷键

### Q: 全局快捷键不生效

**A:** 请检查：
1. 快捷键是否与其他软件冲突（如 QQ、微信、输入法等）
2. 是否以管理员权限运行（部分系统热键需要管理员权限）
3. 设置 → 快捷键中确认热键已启用
4. 尝试重新绑定一个不常用的组合键

### Q: 如何修改/删除快捷键？

**A:** 
1. 打开设置 → 快捷键
2. 找到要修改的功能
3. 点击快捷键输入框，按下新的组合键
4. 点击「应用」保存
5. 如需删除，点击输入框旁的「清除」按钮

## 插件与模板

### Q: 如何安装第三方插件？

**A:** 
1. 下载插件包（通常为 `.zip` 或 `.uniq-plugin`）
2. 打开设置 → 插件
3. 点击「安装插件」按钮，选择下载的文件
4. 或手动将插件解压到：
   ```
   %APPDATA%\Uniquenium\Plugins\
   ```
5. 重启程序

### Q: 插件安装后不显示/不工作

**A:** 请：
1. 检查插件版本是否与 Uniquenium 版本匹配
2. 查看设置 → 插件中是否已启用该插件
3. 打开日志窗口（设置 → 关于 → 查看日志）查看错误信息
4. 联系插件作者或在 GitHub 提交 Issue

### Q: 如何导出/导入页面模板？

**A:** 
1. **导出**：在页面上右键 → 导出为模板 → 选择保存位置
2. **导入**：新建页面时选择「从模板导入」→ 选择模板文件
3. 模板文件包含页面布局和所有组件配置，不包含外部图片资源

## 性能相关

### Q: 程序占用内存过高

**A:** 建议优化：
1. 减少同时显示的组件数量
2. 关闭不必要的插件
3. 降低壁纸模糊半径（设置 → 外观 → 模糊强度）
4. 避免使用过大分辨率的壁纸图片

### Q: 拖动窗口时有卡顿

**A:** 这是 Qt 无边框窗口的已知问题，可尝试：
1. 更新显卡驱动到最新版
2. 关闭不必要的后台程序释放 GPU 资源
3. 在设置中关闭「窗口阴影」和「亚克力效果」

## 开发相关

### Q: 如何获取程序日志？

**A:** 有三种方式：
1. 命令行启动时加 `--debug` 参数，日志直接输出到控制台
2. 设置 → 关于 → 点击「查看日志」按钮
3. 直接打开日志文件：
   ```
   %APPDATA%\Uniquenium\Logs\uniquenium-YYYY-MM-DD.log
   ```

### Q: 如何参与开发或提交代码？

**A:** 欢迎贡献！请：
1. Fork 项目仓库到你的 GitHub 账号
2. 创建新分支开发功能或修复 Bug
3. 确保代码通过现有测试
4. 提交 Pull Request，详细说明修改内容

### Q: 想要的功能没有怎么办？

**A:** 可以：
1. 先查看 [TODO 列表](https://github.com/Uniquenium/Uniquenium/blob/main/TODO.md) 是否已经在计划中
2. 自己开发插件实现（参考[插件开发指南](/custom-developing/plugin.md)）
3. 在 GitHub 提交 Feature Request Issue，详细描述需求和使用场景

## 数据与备份

### Q: 配置文件和数据保存在哪里？

**A:** 用户数据默认保存在：
```
Windows: %APPDATA%\Uniquenium\
├── Pages\         # 页面配置文件
├── Plugins\       # 已安装的插件
├── Settings\      # 程序设置
├── Templates\     # 导出的模板
└── Logs\          # 日志文件
```

### Q: 如何备份和迁移数据？

**A:** 只需将整个 `%APPDATA%\Uniquenium\` 文件夹复制到新电脑的相同位置即可。建议定期备份该文件夹。
