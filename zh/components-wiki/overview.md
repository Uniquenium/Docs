# 组件百科概览

欢迎使用 Uniquenium！本指南将带你了解 Uniquenium 的核心功能和基本操作方法。

## 界面介绍

Uniquenium 的主界面主要由以下几部分组成：

### 托盘区
程序启动后，默认最小化到系统托盘区（任务栏右下角）：
- **左键单击**：显示/隐藏主面板
- **右键单击**：打开托盘菜单，包含：
  - 显示主面板
  - 页面管理
  - 设置
  - 插件管理
  - 退出程序

### 主面板
主面板是 Uniquenium 的核心操作区域，分为：
1. **左侧导航栏**：页面列表，新建/删除/切换页面
2. **中间工作区**：页面画布，组件的显示和编辑区域
3. **右侧属性面板**：选中组件时显示属性编辑选项（编辑模式）

### 编辑模式 vs 浏览模式
Uniquenium 有两种运行模式：
- 🖊️ **编辑模式**：可以添加、删除、拖拽组件，调整属性
- 👁️ **浏览模式**：组件显示正常，但不可修改（日常使用状态）

通过顶部工具栏的「编辑/浏览」切换按钮，或按快捷键 `Ctrl + E` 切换。

## 创建页面

页面是 Uniquenium 组织组件的容器，你可以创建多个独立页面，例如：
- 主面板：放时钟、天气、快捷启动
- 监控面板：放 CPU/内存/网络 监控图表
- 工作面板：放待办事项、便签

### 操作步骤
1. 打开主面板，确保处于**编辑模式**
2. 点击左侧导航栏顶部的 **「+ 新建页面」** 按钮
3. 在弹出的对话框中输入页面名称（例如：「我的主页」）
4. 选择页面样式：
   - **普通面板**：固定大小的窗口面板
   - **全屏遮罩**：覆盖整个屏幕的半透明层
   - **无边框面板**：可自由缩放大小
5. 点击「确定」完成创建

### 页面管理
- **切换页面**：点击左侧导航栏中的页面名称
- **重命名页面**：右键页面 → 重命名
- **删除页面**：右键页面 → 删除（⚠️ 删除后页面内所有组件也会被删除）
- **复制页面**：右键页面 → 复制为新页面
- **导出模板**：右键页面 → 导出为模板（分享或备份）
- **页面排序**：在导航栏中直接拖拽调整顺序

## 添加组件

Uniquenium 提供了多种内置组件，通过插件系统还可以扩展更多。

### 添加步骤
1. 确保处于**编辑模式**
2. 点击工具栏中的 **「添加组件」** 按钮（或按快捷键 `Ctrl + Shift + A`）
3. 在组件选择窗口中，从左侧分类选择组件类型：
   - **基础**：文字、图片、按钮、图标
   - **输入**：文本框、复选框、下拉选择
   - **容器**：框架、选项卡
   - **显示**：图表、进度条、提示框
   - **窗口**：对话框、消息框
   - **自定义**：插件提供的组件
4. 点击或拖拽组件到工作区即可添加

### 常用组件推荐

| 组件 | 用途 | 示例场景 |
|------|------|---------|
| UniDeskText | 显示文字 | 时钟标题、便签内容 |
| UniDeskImage | 显示图片 | 头像、照片墙、Logo |
| UniDeskButton | 点击按钮 | 快捷启动、功能开关 |
| UniDeskFrame | 分组容器 | 将多个组件框在一起 |
| UniDeskChart | 数据图表 | CPU/内存使用率监控 |
| UniDeskTextField | 文本输入 | 待办事项输入框 |
| UniDeskIcon | 图标显示 | 功能图标、状态指示 |

## 组件属性编辑

选中组件后，右侧属性面板会显示该组件可编辑的属性。

### 基础操作

#### 选中组件
- **点击**工作区中的组件即可选中（显示蓝色边框）
- **多选**：按住 `Shift` 依次点击，或拖拽框选多个组件
- **全选**：`Ctrl + A`
- **取消选中**：点击空白处或按 `Esc`

#### 移动与缩放
- **移动**：直接拖拽组件到目标位置
- **精确移动**：选中后用方向键微调（1像素），按住 `Shift` + 方向键每次移动 10 像素
- **缩放**：选中组件后拖拽边缘或角上的控制点
- **保持比例缩放**：按住 `Shift` 拖拽角控制点

#### 复制与删除
- **复制**：选中后按 `Ctrl + C`，再按 `Ctrl + V` 粘贴；或右键 → 复制
- **剪切**：`Ctrl + X`
- **删除**：按 `Delete` 键；或右键 → 删除

### 通用属性

所有组件都具备的通用属性：

| 属性 | 说明 | 示例值 |
|------|------|--------|
| X / Y | 组件左上角坐标（像素） | X: 100, Y: 50 |
| 宽度 / 高度 | 组件尺寸（像素） | W: 200, H: 100 |
| 不透明度 | 0（完全透明）~ 1（完全不透明） | 0.85 |
| 可见性 | 是否显示该组件 | true / false |
| Z 坐标 | 组件叠放顺序，值越大越靠上 | 0, 1, 2... |
| 组件ID | 唯一标识符，用于脚本引用 | myButton_001 |

### 层级调整

组件的层级（Z 轴）决定了重叠时谁显示在上面：
- 右键组件 → **置于顶层**（Z 值设为最大）
- 右键组件 → **置于底层**（Z 值设为最小）
- 右键组件 → **上移一层**（Z 值 +1）
- 右键组件 → **下移一层**（Z 值 -1）
- 在左侧「组件树」面板中直接拖拽调整顺序

### 对齐与分布

选中多个组件后，可使用工具栏对齐按钮：
- ⬅️ 左对齐 / ➡️ 右对齐 / ↕️ 垂直居中
- ⬆️ 顶端对齐 / ⬇️ 底端对齐 / ↔️ 水平居中
- ↔️ 水平等间距 / ↕️ 垂直等间距
- 等宽 / 等高 / 等尺寸

## 快捷键设置

合理使用快捷键可以大幅提升操作效率。Uniquenium 支持丰富的全局热键绑定。

### 默认快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Alt + U` | 显示/隐藏主面板 |
| `Ctrl + Alt + S` | 打开设置窗口 |
| `Ctrl + E` | 切换编辑/浏览模式 |
| `Ctrl + Shift + A` | 添加新组件 |
| `Ctrl + N` | 新建页面 |
| `Ctrl + S` | 保存当前页面 |
| `Ctrl + Z` | 撤销上一步操作 |
| `Ctrl + Shift + Z` | 重做操作 |
| `Delete` | 删除选中组件 |
| `Ctrl + D` | 快速复制选中组件 |

### 自定义快捷键

1. 打开 **设置** → **快捷键** 选项卡
2. 找到要修改的功能，点击快捷键输入框
3. 按下你想要的新组合键（例如：`Ctrl + Alt + H`）
4. 如果提示「已被占用」，请选择其他组合键
5. 点击「应用」保存设置

::: tip 小技巧
- 推荐使用 `Ctrl + Alt + 字母` 或 `Win + Shift + 字母` 作为全局热键，冲突较少
- 数字小键盘的按键也可以绑定，适合频繁操作的功能
:::

### 快捷键冲突处理

如果设置的快捷键不生效：
1. 检查是否被其他软件占用（QQ、微信、输入法、浏览器常用 `Alt + 字母`）
2. 尝试以**管理员身份**运行 Uniquenium（部分系统热键需要更高权限）
3. 修改为一个不常用的组合键，例如 `Ctrl + Shift + F12`

## 主题切换

Uniquenium 支持三种主题模式，完美搭配你的 Windows 外观。

### 切换方式
1. 打开 **设置** → **外观** 选项卡
2. 在「主题模式」中选择：
   - 🌓 **跟随系统**（推荐）：自动同步 Windows 的深色/浅色设置
   - ☀️ **浅色模式**：清新明亮的白色界面
   - 🌙 **深色模式**：护眼省电的黑色界面
3. 点击「应用」立即生效，无需重启

### 主题色设置

除了深浅模式，你还可以自定义强调色（主色调）：
- 在「外观」选项卡中点击「主题色」
- 选择预设颜色，或点击「自定义颜色」使用拾色器
- 所有按钮、高亮、选中框都会自动使用该颜色

### 亚克力效果

UniDesk 控件库支持 **Acrylic 亚克力** 模糊效果（类似 Windows 11 的 Mica 材质）：
- **启用位置**：设置 → 外观 → 启用亚克力效果
- **模糊强度**：调整滑块，值越大背景越模糊（0-100）
- **色彩浓度**：调整面板颜色的不透明度

::: warning 性能提示
亚克力效果会消耗 GPU 资源，如果电脑配置较低或使用电池供电，建议关闭以节省电量。
:::
